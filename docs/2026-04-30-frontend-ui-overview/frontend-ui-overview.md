# 前端界面功能概要说明

- 创建时间：2026-04-30
- 最后更新：2026-04-30
- 适用范围：`src/index.html` 与 `src/main.js` 对应的全部前端界面

## 1. 功能目标

本前端为桌面端 Tauri 单页应用，目标是围绕“麦克风离线语音识别”提供完整操作闭环：

1. 选择输入设备并启动/停止录音识别。
2. 实时查看分段识别结果及状态。
3. 对识别结果执行复制、导出、保存音频等后处理。
4. 配置识别/VAD/LLM 参数并动态生效。
5. 维护词修正规则，提升文本质量。

## 2. 界面清单与概要

### 2.1 主界面（录音与识别工作台）

- 目标：承载日常识别主流程。
- 主要区域：
  - 设备与操作区：输入设备下拉、开始录音、停止录音、清空、词修正入口、设置入口。
  - 自动复制开关：控制新识别文本是否自动写入剪贴板。
  - 状态区：初始化中、进行中、完成、错误提示。
  - 录音指示区：录音红点与已录时长。

### 2.2 结果区（识别结果与回放）

- 目标：展示并消费识别产物。
- 主要区域：
  - 结果操作按钮：复制纯文本、复制带时间文本、导出 SRT、保存整段音频。
  - 音频播放器：回放整段录音。
  - 分段表格：开始/结束/时长/原文/优化文/英文及单段操作。

### 2.3 设置弹窗（VAD 与识别参数）

- 目标：让用户调整识别行为和 LLM 处理参数。
- 参数范围：
  - VAD：阈值、最小静音时长、最小语音时长、最大语音时长。
  - 识别器：线程数。
  - LLM：Provider URL、API Key、模型、Prompt 模板。
- 辅助能力：刷新模型列表、应用/取消。

### 2.4 词修正规则弹窗

- 目标：对识别文本进行词级纠正策略管理。
- 主要能力：
  - 查看规则列表（启用、源词、目标词、优先级）。
  - 新增规则。
  - 启用/禁用规则。
  - 修改优先级。
  - 删除规则。

## 3. 核心流程（用户视角）

### 3.1 初始化流程

1. 页面加载后轮询模型初始化状态。
2. 并行加载输入设备列表、历史最新会话、词修正规则。
3. 模型就绪且存在可用麦克风后，启用核心操作按钮。
4. 满足条件时自动触发一次开始录音。

### 3.2 录音识别流程

1. 用户点击开始录音。
2. 前端进入录音态：禁用设置/清空/设备切换，显示计时器。
3. 轮询录音状态与分段结果，持续追加到结果表格。
4. 每次新分段到达时按条件执行自动复制。
5. 用户点击停止后等待后端结束，恢复非录音态并加载可回放音频。

### 3.3 结果消费流程

1. 用户可复制全部文本或带时间文本。
2. 用户可导出 SRT。
3. 用户可保存整段录音为 WAV。
4. 用户可点击分段行跳转播放器时间并播放。
5. 用户可对单段执行“复制文本”或“导出单段 WAV”。

### 3.4 参数与规则维护流程

1. 打开设置弹窗，读取当前参数并可刷新模型列表。
2. 应用设置后触发模型重载，重载期间暂停可录音状态。
3. 打开词修正弹窗后加载规则。
4. 规则新增/更新/删除后触发后端规则重载并刷新列表。

## 4. 核心交互说明

1. 状态驱动禁用：模型未就绪、无设备、录音中等状态会动态限制按钮可用性。
2. 自动复制节流：默认开启，避免高频写剪贴板；相同文本不重复复制。
3. 表格与播放器联动：播放时高亮当前分段；点击分段可定位播放。
4. 轻提示反馈：复制成功、保存成功、规则更新、异常等通过状态栏短时提示。
5. 外链行为：页面内文档链接通过系统默认浏览器打开。

## 5. 边界与约束

1. 单页形态：当前无多路由页面，所有“界面”以主界面和弹窗子界面构成。
2. 初始化依赖：模型初始化失败时无法进入录音流程。
3. 设备依赖：未检测到麦克风时录音入口不可用。
4. 录音互斥：录音过程中不允许改设置、切设备或清空结果。
5. 数据展示边界：前端展示依赖后端轮询数据；优化文与英文仅在后端状态为完成时显示。
6. 文件输出边界：导出 SRT/WAV 依赖本地路径选择与后端写文件成功。
7. 词修正约束：源词不能为空，优先级必须为整数。
8. 参数校验约束：阈值/时长/线程数在前端有输入范围校验，非法值不可提交。

## 6. 非目标（本说明不覆盖）

1. 后端 ASR/VAD/LLM 算法细节与模型文件组织。
2. 数据库存储结构与迁移策略。
3. 多用户、多会话协同等服务端能力。
