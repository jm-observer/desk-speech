# 剪贴板同步策略重构

- 时间：2026-05-01
- 项目现状：当前前后端均存在自动复制逻辑，导致剪贴板内容在中文（前端自动/手动）与英文（后端自动）之间产生竞争，执行结果不确定。
- 整体目标：明确前后端职责，消除竞争条件，确保用户对剪贴板内容有确定的预期。
- 默认策略：`auto_copy_mode` 默认值为 `English`，即默认自动复制英文；中文与英文的手动复制均由前端独立按钮触发。

## 设计原则
1. **职责分离**：
   - **后端**：负责“流式增量”的自动复制。主要面向即时翻译场景，将最新识别并翻译好的内容推送到剪贴板。
   - **前端**：负责“全量/精细”的手动复制。提供 UI 按钮供用户按需复制整篇中文、英文或带时间戳的内容。
2. **配置显式化**：
   - 自动复制内容应由用户在设置中明确选择（如：关闭、仅英文、仅优化中文）。
   - 默认行为应符合用户偏好（后端自动复制英文，前端提供手动复制中文的按钮）。
3. **持久化一致性**：
   - 自动复制模式属于用户设置项，需持久化到数据库（或统一设置存储），并提供向后兼容迁移策略。

## 风险与待定项
- **剪贴板竞争**：即使职责分离，如果用户在自动复制发生的瞬间执行手动复制，仍可能存在极短时间的覆盖风险。需在 UI 上通过状态提示（如“已自动复制英文”）引导用户。
