## 本次目标
- 补齐前端配置界面与配置入库。
- 结果区按 3 行展示：原始文本、优化文本、英文翻译。

## 涉及文件
- `src/**/settings*`
- `src/**/result*`
- `src/**/api*`
- `schema/` 对应前端类型文件

## 详细设计
- 配置界面：
  - 字段：`provider_url`、`api_key`、`selected_model`、`prompt_template`、VAD。
  - 模型列表：请求后端接口，后端负责 5 分钟缓存。
  - 配置提交后入库，供后端任务读取。
- 三行展示：
  - 第 1 行：原始文本（始终显示）。
  - 第 2 行：优化文本（仅成功时显示）。
  - 第 3 行：英文翻译（仅成功时显示）。
- 失败显示策略：
  - LLM 失败时仅显示第 1 行原始文本，第 2/3 行隐藏。
  - 前端不因 LLM 失败中断主视图更新。

## 测试案例
- 正常路径：配置保存成功，三行按时序更新。
- 边界条件：优化结果延迟到达时 UI 正确覆盖第 2/3 行。
- 异常场景：LLM 失败仅保留原始文本展示。
