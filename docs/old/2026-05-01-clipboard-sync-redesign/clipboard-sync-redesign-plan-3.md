# Plan 3: 手动复制功能增强

## 前置依赖
Plan 2

## 本次目标
1. 提供“复制中文”“复制英文”两个独立手动复制按钮，分别对应不同文本源。
2. 增强手动复制按钮的反馈效果。
3. 确保手动复制的内容不受自动推送逻辑的实时覆盖干扰。

## 涉及文件
- `src/src/App.tsx`: 优化手动复制按钮回调。
- `src/src/components/ui/Button.tsx`: (如果需要) 增加成功提示状态。

## 详细设计

### 1. 交互增强
- 在主结果区同时展示两个并列按钮：
  - `复制中文`：复制当前聚合后的中文文本
  - `复制英文`：复制当前聚合后的英文文本
- 当用户点击任一按钮后，仅该按钮文字短暂变为“已复制！”并改变图标，另一按钮状态不受影响。
- 考虑到后端可能会在手动复制后立即推送新内容，前端在手动复制成功后应在 UI 上给出更明显的提示，使用户意识到手动复制操作已完成。

### 2. 逻辑优化
- 手动复制逻辑应获取当前 `store.segments` 的最新快照。
- 中文与英文分别走独立的提取函数，避免按钮共用一套拼接逻辑导致文案串用。
- 手动复制事件不改写 `auto_copy_mode`，避免 UI 操作与自动复制配置耦合。

## 测试案例
- **交互验证**：连续点击复制按钮，检查状态反馈是否正常。
- **全量验证**：在录音结束后，手动点击“复制中文”，检查是否包含所有段落。
- **全量验证**：在录音结束后，手动点击“复制英文”，检查是否包含所有段落。
- **隔离验证**：点击“复制中文”后，“复制英文”按钮状态不应被置为“已复制”。
