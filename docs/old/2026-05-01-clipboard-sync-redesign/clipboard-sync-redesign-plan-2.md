# Plan 2: 前端自动复制逻辑重构

## 前置依赖
Plan 1

## 本次目标
1. 移除 `App.tsx` 中冗余的 `useEffect` 自动复制逻辑。
2. 更新设置面板，支持 `auto_copy_mode` 的切换与持久化。
3. 明确默认展示与初始化逻辑：首次进入时默认选中“自动复制英文”。

## 涉及文件
- `src/src/App.tsx`: 移除自动复制逻辑。
- `src/src/components/SettingsModal.tsx`: 增加配置 UI。
- `src/src/api/tauri-client.ts`: 更新接口定义。

## 详细设计

### 1. 逻辑清理
- 删除 `App.tsx` 中监听 `store.segments` 变化并调用 `copyToClipboard` 的 `useEffect`。
- 保留 `copiedRawKeysRef` 等用于其他目的（如 UI 标记）的逻辑，但不再触发剪贴板写入。

### 2. UI 更新
- 在 `SettingsModal` 中将原本的 `Auto Copy` 开关升级为下拉菜单或单选组。
- 选项包括：
  - 关闭
  - 自动复制英文 (由后端流式推送)
  - 自动复制中文 (由后端流式推送)
- 前端初始化时读取后端设置值；若返回缺失字段（兼容旧版本），前端回退显示 `English`，并在首次保存时写回标准值。

## 测试案例
- **功能验证**：开启前端设置后，观察后端推送是否生效。
- **功能验证**：关闭前端设置后，确保识别过程中剪贴板不再发生变化。
- **兼容验证**：连接包含旧配置数据的环境，设置面板默认显示“自动复制英文”。
