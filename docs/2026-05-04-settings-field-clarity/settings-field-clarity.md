## 问题归纳

1. 字段识别依赖 `placeholder`，输入后语义消失。
2. 页签仅按技术域拆分，未在页内提供“本组参数影响什么”的上下文说明。
3. 数值型字段没有单位、推荐值、合法范围、错误提示与填写示例。
4. LLM 配置中的 URL、模型、提示词、自动复制策略语义层次不清，用户容易混淆“服务接入配置”和“文本处理策略”。
5. 保存动作缺少“哪些值有问题、为什么不能保存”的就地反馈，只能依赖后端报错。

## 设计原则

1. 固定标签优先：字段名称必须在输入后仍可见，`placeholder` 仅作为示例，不承担唯一语义。
2. 说明分层：每个字段至少具备“名称 + 一句话用途”，复杂字段额外补充“单位/范围/示例/风险”。
3. 就近反馈：校验、错误、推荐值、加载状态都贴近字段展示，避免弹窗式打断。
4. 结构稳定：同类字段使用统一容器和视觉层级，降低扫描成本。
5. 渐进暴露：默认先展示填写所需的核心信息，细节说明通过帮助文本、提示块或折叠说明补充。

## 目标页面结构

### 一级结构

1. 弹窗顶部：
   - 标题：`识别参数设置`
   - 副标题：说明“参数影响分段、识别性能和 LLM 后处理效果，修改后会重载模型”
2. 页签层：
   - `VAD 分段`
   - `ASR 识别`
   - `LLM 后处理`
3. 页签内容层：
   - 每个页签顶部增加一段分组说明，先解释该分组影响什么，再进入具体字段。
4. 底部操作层：
   - 左侧可放保存风险提示，如“修改后会重新加载识别模型”
   - 右侧保留取消与保存按钮

### 字段层结构

每个字段统一采用如下层次：

1. 字段标签：始终可见，中文优先，必要时补充英文键名。
2. 字段副说明：一句话说明用途。
3. 输入控件：文本框 / 数值框 / 下拉框 / 文本域。
4. 辅助信息行：展示单位、范围、示例值、默认值或加载状态。
5. 校验信息行：仅在异常时出现，说明为什么错误、如何修正。

## 字段语义文案建议

### VAD 分段

分组说明：控制系统如何判断“开始说话”和“停止说话”，会直接影响分段频率、漏切和误切。

1. `threshold`
   - 标签：`静音阈值`
   - 说明：控制语音与静音的分界敏感度。
   - 辅助信息：`取值范围 0~1，推荐 0.2`
   - 风险提示：值越小越容易判定为语音，值越大越容易截断轻声。
2. `min_silence_duration`
   - 标签：`最小静音时长`
   - 说明：连续静音达到该时长后，才会切分一段语音。
   - 辅助信息：`单位：秒，推荐 0.2`
3. `min_speech_duration`
   - 标签：`最小语音时长`
   - 说明：短于该时长的语音片段会被忽略或合并。
   - 辅助信息：`单位：秒，推荐 0.2`
4. `max_speech_duration`
   - 标签：`最大语音时长`
   - 说明：单段语音的最长持续时间，超出后强制切段。
   - 辅助信息：`单位：秒，必须大于 0，推荐 10`

### ASR 识别

分组说明：控制本地识别模型的并行度，主要影响 CPU 占用与识别速度。

1. `num_threads`
   - 标签：`识别线程数`
   - 说明：用于加载和运行识别模型的线程数量。
   - 辅助信息：`取值范围 1~16，推荐按 CPU 核心数调整`
   - 风险提示：线程数过高可能导致系统卡顿，过低会影响识别速度。

### LLM 后处理

分组说明：配置远程模型接入与文本后处理策略，影响润色、翻译和自动复制结果。

1. `auto_copy_mode`
   - 标签：`自动复制策略`
   - 说明：决定识别完成后自动写入剪贴板的文本版本。
   - 选项文案：
     - `关闭`：不自动复制
     - `自动复制英文`：复制翻译结果
     - `自动复制中文`：复制优化后的中文
2. `provider_url`
   - 标签：`模型服务地址`
   - 说明：兼容 OpenAI 接口的服务根地址。
   - 辅助信息：`示例：https://api.openai.com/v1`
3. `api_key`
   - 标签：`API Key`
   - 说明：调用模型服务所需的鉴权令牌。
   - 辅助信息：`建议默认遮罩显示，仅在编辑时明文输入`
4. `selected_model`
   - 标签：`默认模型`
   - 说明：用于润色与翻译的模型名称。
   - 辅助信息：展示 `正在加载模型列表`、`加载失败，可保留当前值`、`当前已保存值`
5. `optimize_prompt_template`
   - 标签：`润色提示词`
   - 说明：定义纠错、去噪、补标点的系统提示词。
   - 辅助信息：提示“需返回 JSON 且包含 `text_optimized`”
6. `translate_prompt_template`
   - 标签：`翻译提示词`
   - 说明：定义中文转英文的系统提示词。
   - 辅助信息：提示“需返回 JSON 且包含 `text_english`”

## 预期收益

1. 用户在填写后仍能通过固定标签识别每个值的含义。
2. 参数的单位、范围和推荐值更清晰，误填成本下降。
3. 保存失败时用户能更快定位到具体字段，而不是只看到一条总错误。
4. 设置页可以作为“可维护配置面板”持续扩展，不再依赖零散 placeholder。
