# Manual Test Checklist

## 基本回归
- 启动应用后可正常识别、停止、导出 SRT、保存音频。
- 重启应用后可加载最近会话与词修正规则。

## 词修正
- 新增规则后列表即时刷新。
- 禁用规则后新分段不再应用该规则。
- 删除规则后列表移除并立即生效。

## 自动复制
- 默认开启，新增分段会自动复制 `text_corrected`。
- 关闭开关后不再复制。
- 快速连续分段时复制节流生效（>=500ms）。
- 剪贴板异常时展示错误提示，但识别流程持续。

## 长录制
- 连续录制 30 分钟，观察内存占用稳定，不随时长线性增长。
- 停止后能正常回放与导出。
